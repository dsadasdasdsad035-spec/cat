# 真实拍摄清单

## 开拍前
- [ ] 手机/相机设置为竖屏9:16
- [ ] 清洁镜头，尽量使用自然光
- [ ] 准备猫咪熟悉的毯子、猫窝、食物和水
- [ ] 准备稳定支架或低机位支撑
- [ ] 先让猫咪适应拍摄环境，不强迫摆拍
- [ ] 拍摄前检查画面是否暴露住址、个人信息或敏感屏幕内容

## 第一集必拍镜头
- [ ] 猫咪眼睛特写：自然抬头、眨眼、观察
- [ ] 猫咪躲藏：沙发边、猫窝边或毯子旁的自然反应
- [ ] 人的手靠近：缓慢伸手，猫咪可以自由离开
- [ ] 猫咪探索：探头、闻气味、观察门口和走廊
- [ ] 放下食物和水：拍摄人放下后退开的连续动作
- [ ] 猫咪进食：保持距离，不打扰
- [ ] 猫咪抬头看人：多录几次，后期选自然的一条
- [ ] 猫咪休息：熟悉的毯子或猫窝，温暖结尾
- [ ] 环境空镜：门、走廊、地面、窗边、房间光线
- [ ] 人类视角：脚步、开门、坐到地面、放食物

## 拍摄方法
- 每段连续录10—20秒，后期再剪成2—8秒镜头。
- 多拍几个角度：正面、侧面、背影、爪子、眼睛。
- 镜头高度尽量贴近猫咪，能明显增强主观视角。
- 记录真实环境音：脚步、开门、碗轻响、房间底噪。
- 不要强行让猫咪重复动作；真实反应比表演更有感染力。

## 安全与真实性
- 不把家猫放进污水、排水沟、暴雨、车流或其他危险场景。
- 不为了镜头强行抱起、限制或惊吓猫咪。
- 厨房实拍时让猫咪远离火源、热锅、刀具和有害食材。
- AI野外镜头如果不是历史真实记录，应作为故事化回忆，不要伪装成真实救助证据。
