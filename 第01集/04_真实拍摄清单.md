# 真实拍摄清单

本清单只服务第1集镜头 07–12。镜头 01–06 是雨夜回忆，全部用 AI，不要把家猫带出门拍。

分镜与旁白以 `03_第1集完整剧本与分镜.md` 为准。

## 开拍前
- [ ] 手机或相机设为竖屏 9:16，分辨率至少 1080×1920
- [ ] 清洁镜头。室内用自然光或原有的暖灯光，不要打强闪光
- [ ] 准备猫愿意靠近的黄色织物、水碗、食碗、日常猫粮
- [ ] 准备离地约 8–15 cm 的稳定支撑：迷你三脚架、翻过来的硬盒，或让手机靠墙
- [ ] 先让猫在这个房间自由走几分钟，再开机
- [ ] 白猫留在另一个房间，或确认本条不会入画
- [ ] 电脑屏幕关闭或背对镜头。检查画面里没有住址、账单和聊天内容
- [ ] 铲屎官两句台词先在安静处单独录好，不要突然对着猫提高音量

## 场景与走位
- 房间用猫熟悉的室内。竖屏里少出现带品牌的杂物。
- 黄色织物放在它习惯躲的地方。第1集不要拍「人把毯子安放到角落、道晚安」，那个动作留给第2集。
- 走位：猫的退路留在画面一侧，人从另一侧进来。碗放在人和猫之间、略靠近人。人放下碗就退到焦外。
- 镜头中心贴近猫眼。不要站着俯拍。
- 眼睛特写可用手机 2 倍左右；主观和全身用 1 倍贴地，让人的腿显得高。

## 必拍镜头
每条连续录 10–20 秒，多留几秒开头和结尾。成片时间看分镜表，不在现场卡秒。

- [ ] 镜头 07：门锁声里，猫趴在黄色织物后打量房间。身体压低，耳朵半转。正面、侧面各一条
- [ ] 镜头 07 空镜：门、走廊、地面、窗边暖光。每条 5–8 秒即可
- [ ] 镜头 08：手把水碗和食碗放下，手退出画面。连拍，不要只拍静物
- [ ] 镜头 08 反打：猫看着碗的方向，但前爪不往前
- [ ] 镜头 09：从织物后露出半张脸，看碗，再看人。只要探头，不要走过去吃
- [ ] 镜头 10：眼睛极近，自然看向人。多录几次眨眼和瞳孔变化，后期选最稳的一条做蓝光
- [ ] 镜头 11：下巴搁回织物，眼睛睁着，视线朝门口。人只在远处虚焦
- [ ] 备用：爪子、白胸、侧面花纹各一条，给 AI 对形，不进「吃东西」情节

猫如果当天不愿意探头，就用它自己露出眼睛的素材。镜头 09 可以只剩一双眼睛，只要「不过去吃」还在。不要用声音、零食罐或道具逼它。

## 建议拍摄顺序
1. 先拍眼睛和探头。猫还清醒、也不饿到必须奔向碗的时候，表情更干净。
2. 再拍放碗和退开。碗放下之后不要立刻加餐，避免它马上开吃。
3. 最后拍看向门口的近景。
4. 白猫的素材另日再拍，不混进第1集卡带。

## 要单独录的声音
- [ ] 室内底噪 20 秒，同机位、无人说话
- [ ] 门锁和门轴
- [ ] 空碗轻碰地面一下；有猫粮的碗再碰一下，选更轻的那条
- [ ] 「小家伙，你怎么在这里？」
- [ ] 「别怕。慢慢来。」
- [ ] 不要录真实暴雨环境里的猫。雨声后期再铺，只用于镜头 01–06

## 不要剪进第1集的素材
- 进食、喝水的特写。留给第2集。
- 猫闭上眼睡着，或人把毯子放到角落。
- 白猫的任何出镜。
- 屏幕上的文字、简历、账单。
- 猫被抱住挣扎、被拎起来、被堵住退路。

## 安全与真实性
- 不把家猫放进污水、排水沟、暴雨、车流或其他危险场景。
- 不为了镜头强行抱起、限制或惊吓猫咪。
- 厨房不在本集。若猫自己走到厨房，停机，让它离开火源、热锅和刀具。
- 食碗里只用它平时吃的东西。
- AI 雨夜如果不是历史真实记录，就当故事化回忆，不伪装成真实救助证据。
