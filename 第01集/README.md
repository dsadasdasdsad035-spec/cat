## 第1集怎么用

1. 先读 `完整剧本与分镜.md`。改这一集的故事只改这一份。
2. 主角是蓝眼睛白色小猫，约两个月，身体很瘦、营养不良。不是狸花。
3. 主线只有这一夜：独自在野外，下雨，体温往下掉，走进下水道。下水道里的水可能是附近医药工厂流出的化工废水。
4. 按真实经历剪。危险镜头用 AI 复原，因为不能把猫放进雨里、下水道和化工排水。不要再打「故事化回忆」，也不要在文案里写「不是真实救助记录」。
5. 家中白猫的实拍只用来锁定脸和眼色，不代替雨夜里那只更小、更瘦的猫。
6. 第2集接的是「已经到家」之后。第1集不要演获救。第2集剧本在 [`../第02集/完整剧本.md`](../第02集/完整剧本.md)；旧稿里的狸花主角与本集冲突，以系列设定里的冲突清单为准。

## 制作原则

- 真实白猫照片是脸、眼色、粉鼻、粉耳和毛长的依据。第1集的年龄和瘦弱程度按设定锁定，照片里没有这一阶段。
- 无猫的雨景、管口外观、公共场所里的厂房远景可以实拍。
- 有猫的野外、雨夜、下水道、污水，全部 AI。
- 不要为了拍摄把猫放入污水、道路、暴雨、冷暴露、火源或其他危险环境。
- 不要为了画面让猫挨饿。
