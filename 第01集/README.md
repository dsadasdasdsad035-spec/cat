# 第1集《我差点没活过那个雨夜》

本文件夹只放第1集的制作资料。系列设定、前10集大纲和参考照片在仓库别处，各有一份，不复制到这里。

## 本集文件

1. [`完整剧本与分镜.md`](完整剧本与分镜.md)：本集唯一主剧本，含逐镜头、旁白和声音设计。
2. [`真实拍摄清单.md`](真实拍摄清单.md)：进门之后的实拍准备、镜头清单和动物安全。
3. [`AI镜头生成提示词.md`](AI镜头生成提示词.md)：雨夜回忆镜头的英文提示词。
4. [`剪辑与发布规范.md`](剪辑与发布规范.md)：竖屏剪辑、字幕、封面和真实性处理。

## 系列共享

- 角色与项目设定：[`../系列设定/项目设定与角色档案.md`](../系列设定/项目设定与角色档案.md)

## 第1集怎么用

1. 先读 `完整剧本与分镜.md`。改这一集的故事只改这一份。
2. 实拍按 `真实拍摄清单.md`，只覆盖进门之后的镜头。
3. 雨夜按 `AI镜头生成提示词.md` 生成，并套用真实狸花的参考照片。
4. 剪辑、字幕、角标和发布文案按 `剪辑与发布规范.md`。
5. 第2集接的是同一夜的后半段：猫还没吃、还没睡。不要在第1集把信任演完。第2集剧本在 [`../第02集/完整剧本.md`](../第02集/完整剧本.md)。

## 制作原则

- 真实猫咪素材作为角色外观的主要依据。
- 真实家庭、真实猫咪互动、真实农村和城市环境优先实拍。
- 野外受困、危险环境、宫廷穿越、超能力等难以或不宜实拍的内容用AI生成。
- 不要为了拍摄把猫放入污水、道路、暴雨、火源或其他危险环境。
- 如果野外经历并非有真实影像证明，应作为故事化回忆呈现，不要宣称AI画面是真实救助记录。
