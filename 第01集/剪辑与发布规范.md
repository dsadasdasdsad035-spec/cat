# 剪辑与发布规范

成片按 `完整剧本与分镜.md` 的 12 个镜头剪。本文件只规定剪法和发布，不改故事。

## 画面
- 竖屏 9:16，建议输出 1080×1920、30 fps。
- 前 3 秒就是雨夜里的猫眼，不先放片头，不先放系列标题。
- 镜头 01–06：偏冷、略降饱和、细颗粒，让人看出这是回忆。
- 镜头 06 到 07：大约 8 帧溶化。声音上雨切到门锁，色温从冷转到室内暖光。
- 镜头 07–12：保留实拍的自然光。黄色织物是暖色锚点，不要再套雨夜的冷色。
- AI 镜头保持写实，不做卡通，也不做夸张变身。
- 字幕和角标躲开眼睛、白爪和花纹。

## 节奏
- 0:00–0:17 心疼：眼、雨、冷和饿。信息少，雨声大。
- 0:17–0:40 紧张：鞋停住，手停在一臂外。这里不要配完整旋律。
- 0:40–0:66 温暖：门、房间、放下的碗、停住的手。猫仍然不过去吃。
- 0:66–0:78 悬念：不上字幕，不上旁白，只留极淡蓝光。
- 0:78–0:90 旁白回来，最后一幅仍是那点蓝，然后黑场。半秒全静。

若要压到大约 75 秒：缩短镜头 03 和镜头 11，不剪蓝光，不剪雨到门锁的声桥。
若素材里的等待很自然、全片放到 2 分钟：只加长镜头 09 的停顿。不加进食，不加白猫，不加能力解释。

## 声音
- 镜头 01–04：近处雨、远处车。无音乐，无炸雷。
- 镜头 05–06：雨退后，人声低于平时说话。钢琴只进一个音。
- 镜头 07–09：室内底噪、门锁、碗轻响一次。音乐一直低于旁白。
- 镜头 10：旁白和音乐都让开。低频很短，不做能量爆发。
- 镜头 12：最后半秒全静，方便黑场落地。
- 旁白和两句人声都要有字幕。很多观众会静音观看。
- 响度可按短视频习惯混到大约 -14 LUFS，真峰值不超过 -1 dBTP。雨声不要盖过旁白。

## 字幕
白字，必要时加很窄的半透明底。一行一事，不挡猫脸。猫在画面下半时，字幕上移。

| 时间 | 字幕 |
|---|---|
| 0:00 | 那天晚上，我以为自己活不过去了。 |
| 0:05 | 外面一直在下雨。 |
| 0:12 | 我又冷，又饿。 |
| 0:18 | 我不知道家在哪里。 |
| 0:25 | 小家伙，你怎么在这里？ |
| 0:33 | 我不知道他会不会伤害我。 |
| 0:41 | 后来，我来到了一个从没见过的世界。 |
| 0:50 | 别怕。慢慢来。 |
| 0:57 | 他没有赶我走。 |
| 0:60 | 那只手停下来，没有抓我。 |
| 0:63 | 原来，人类的手也可以这么温柔。 |
| 0:66–0:78 | 无字幕 |
| 0:79 | 我以为，活下来就够了。 |
| 0:86 | 可我不知道……这个家，会改变我的一生。 |

0:57 之后的三句已经拆开。若画面里仍嫌挤，就保持这个拆分，不要合成一块大字。

## 角标与真实性
- 镜头 01–06 左下角小字：「故事化回忆」。字小，不挡猫。
- 镜头 07 起拿掉这个角标。
- 不要给雨夜加监控时间、定位、新闻滚条或救助日期。
- 简介或置顶评论写明：「本系列采用真实猫咪日常与 AI 故事化场景。雨夜及奇幻画面为创作演绎，不是真实救助记录。」

## 封面
文案：**被捡回家的那天，我的人生改变了。**
封面用主角狸花的真实照片。若用 AI 雨夜做封面，封面或标题旁要能看出这是故事，不能让人以为那是未经说明的现场记录。

## 发布文案
它那天晚上只想活下来。手停在那里，没有抓它。它还不知道，这个家会改变什么。片中雨夜为故事化回忆，不是真实救助记录。#猫猫养家日记 #猫咪日常 #AI短剧

## 不要这样剪
- 不要把吃东西、喝水、睡着的备用镜头放进第1集。第2集还要用「第一次吃、第一次没有盯着出口」。
- 不要在结尾打出「人类视觉模式已解锁」。
- 不要用白猫的蓝眼睛代替狸花瞳孔里的反光。
- 不要在本集解释铲屎官失业。电脑屏幕关掉或打码。
- 片尾停在蓝光和黑场，不接下一集的预告画面。
