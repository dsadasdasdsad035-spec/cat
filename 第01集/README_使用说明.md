# 《猫猫养家日记》前期制作资料包

本资料包基于当前对话中的设定整理，适合先制作第一集样片，再继续扩展前10集。

## 资料清单

1. `01_项目设定与角色档案.md`：系列定位、两只猫的角色设定、视觉一致性要求。
2. `02_前10集分集大纲.md`：前10集故事走向。
3. `03_第1集完整剧本与分镜.md`：约90秒第一集的逐镜头脚本、旁白、声音设计。
4. `04_真实拍摄清单.md`：实拍准备、镜头清单和动物安全注意事项。
5. `05_AI镜头生成提示词.md`：第一集AI镜头的英文提示词和制作建议。
6. `06_剪辑与发布规范.md`：竖屏剪辑、字幕、封面和真实性处理建议。

## 制作原则

- 真实猫咪素材作为角色外观的主要依据。
- 真实家庭、真实猫咪互动、真实农村和城市环境优先实拍。
- 野外受困、危险环境、宫廷穿越、超能力等难以或不宜实拍的内容用AI生成。
- 不要为了拍摄把猫放入污水、道路、暴雨、火源或其他危险环境。
- 如果野外经历并非有真实影像证明，应作为故事化回忆呈现，不要宣称AI画面是真实救助记录。
