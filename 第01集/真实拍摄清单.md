# 真实拍摄清单

本集叙事里的猫全部用 AI 复原，对应 `完整剧本与分镜.md` 的镜头 01–12。真实拍摄只做两件事：没有猫的空镜，以及家中白猫的外观参考。参考镜头不剪进雨夜。

分镜与旁白以 `完整剧本与分镜.md` 为准。

## 开拍前
- [ ] 手机或相机设为竖屏 9:16，分辨率至少 1080×1920
- [ ] 先分清两类卡带：空镜、参考。不要和 AI 成片混在同一个未命名相册里
- [ ] 确认猫在干燥、温暖的室内。本集没有任何「带猫出门」的镜头
- [ ] 狸花不要入画。第1集主角不是它
- [ ] 空镜画面里没有可识别的厂名、车牌、住址、人脸和聊天内容
- [ ] 旁白在安静室内单独录，不对着猫提高音量

## 可以拍的空镜
每条 5–10 秒。空镜里不能有猫，也不能有人伸手进排水设施。

- [ ] 镜头 02 可用：夜雨打在路面或泥地上，积水反光。人站在安全的人行道上，不站进车流
- [ ] 镜头 06 可用：下水道口的外观。只在护栏或人行道外拍。不掀井盖，不进入，不探身，不伸手，不取水
- [ ] 镜头 09 可用：从公共道路看见的厂房夜间轮廓，要远、要虚。不进入厂区，不靠近排放口，不拍厂名和标志
- [ ] 室内或窗边的雨声环境 20 秒，给后期参考。这不是猫的环境声

没有这些空镜也可以。12 个镜头允许全部用 AI。不要为了凑空镜进入下水道或厂区。

## 可以拍的参考镜头
对象是家里现在这只蓝眼白猫。它比第1集里的两个月幼猫更大、体况已经恢复。这些条只供给 AI 对形，不剪进第1集成片。

- [ ] 正面：蓝眼睛、粉色鼻头、白短毛，对应 [`../猫咪真实参考照片/微信图片_20261028095803_29_213.jpg`](../猫咪真实参考照片/微信图片_20261028095803_29_213.jpg)
- [ ] 坐姿全身：耳、爪、体态，对应 [`../猫咪真实参考照片/微信图片_20261028095806_31_213.jpg`](../猫咪真实参考照片/微信图片_20261028095806_31_213.jpg)
- [ ] 背面：耳内粉色、背上没有斑纹，对应 [`../猫咪真实参考照片/微信图片_20261028095805_30_213.jpg`](../猫咪真实参考照片/微信图片_20261028095805_30_213.jpg)
- [ ] 自然眨眼两三次。不要用闪光直射眼睛

拍参考时让它自己待在熟悉的房间。不喷水，不弄脏，不要求它发抖。

## 建议顺序
1. 先拍参考。猫清醒、房间安静的时候，眼睛颜色最准。
2. 猫离开现场之后，再考虑夜雨空镜。不要把猫装进包里一起去。
3. 旁白最后录，按 `完整剧本与分镜.md` 的旁白稿，不要临场改情节。

## 要单独录的声音
- [ ] 安静室内底噪 20 秒
- [ ] 窗边或屋檐下的雨，人在室内录
- [ ] 若能在安全距离听到排水管的滴答，可以录，人不进入管道
- [ ] 完整旁白一条
- [ ] 不要录猫待在暴雨、下水道或工厂附近时的声音

## 不要剪进第1集的素材
- 家中白猫任何一张「现在」的实拍，包括吃饭、睡觉、玩逗猫棒。
- 狸花的任何出镜。
- 人的手、鞋、房间、碗、毯子。那些不是这一夜。
- 猫被淋湿、被放进冷处、被关进狭窄空间换来的素材。
- 井盖打开后的管井内部、排放口近景、水样、可读厂名。

## 安全
- 不把家猫放进污水、排水沟、暴雨、车流、工厂或任何低温环境。
- 不为了「两个月、很瘦」限制饮食，也不为了发抖给它降温。
- 人不进入下水道，不接触管里的水，不采集水样，不进入厂区。
- 空镜若开始觉得脚下湿滑或靠近车流，就停。
- 厨房、火源、热锅、刀具不在本集。
