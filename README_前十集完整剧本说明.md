# 《猫猫养家日记》前十集完整剧本包

本压缩包包含第1—10集独立剧本，每集均含故事梗概、逐镜头分镜表、完整旁白稿、实拍/AI制作方式与注意事项。

- 画幅：9:16竖屏
- 单集目标：约90秒，可按素材剪辑为1—2分钟
- 风格：真实猫咪实拍 + AI故事化回忆/奇幻镜头
- 角色：狸花白手套猫为主角，蓝眼睛白猫为搭档，35岁程序员铲屎官为人类主线角色

第1集另有前期制作包，路径为 `第01集/`。其中分镜、旁白与根目录 `第01集_我差点没活过那个雨夜.md` 保持同步；拍摄清单、AI 提示词和剪辑规范也以该分镜为准。

注意：本包是可执行的前期剧本稿。AI镜头中的野外经历属于故事化演绎，除非有真实历史影像，不应当作真实救助记录发布。
