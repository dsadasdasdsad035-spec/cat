# 《猫猫养家日记》

竖屏短片系列。前10集剧本和第1集前期制作包都在这个仓库里。

- 画幅：9:16 竖屏
- 单集目标：约 90 秒，可按素材剪到 1—2 分钟
- 第1集：蓝眼睛白色小猫的真实经历。约两个月，身体很瘦。雨夜体温往下掉，走进一条可能混有医药工厂化工废水的下水道
- 制作：危险环境用 AI 复原，因为不能把猫放进暴雨、下水道和化工排水。这不改变经历本身
- 后续各集：第2–10集正文仍按旧设定写狸花主角。冲突记在系列设定里，正文本次未整集重写
- 人类角色：35 岁程序员铲屎官。第1集不出场

## 目录约定

一集一个文件夹。该集的主剧本、分镜，以及拍摄、AI、剪辑等配套，只放在这一集的文件夹里。系列级资料只放一份，不复制进每一集。

| 位置 | 放什么 |
|---|---|
| `第01集/` … `第10集/` | 这一集的权威剧本。第1集另有拍摄清单、AI 提示词和剪辑规范 |
| [`系列设定/`](系列设定/README.md) | 全系列角色档案、前10集大纲、设定冲突 |
| [`猫咪真实参考照片/`](猫咪真实参考照片/README.md) | 白猫与狸花的真实参考图。第1集主角用白猫 |
| `README.md` | 本说明 |

根目录不再保留 `第01集_….md` 这种单集剧本。改某一集的故事，只改该集文件夹里的主剧本。

## 真实性与安全

第1集按这只蓝眼白猫的真实经历讲述，不再标成「故事化回忆」，也不再用「不是真实救助记录」否定那个雨夜。

没有办法安全实拍的场面（暴雨中的幼猫、下水道、疑似化工废水）用 AI 复原。拍摄时猫不在这些环境里。不要为了拍摄把猫放入污水、道路、暴雨、低温、火源或其他危险环境，也不要为了「看起来很瘦」限制它进食。
