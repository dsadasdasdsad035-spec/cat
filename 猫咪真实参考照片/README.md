## 使用说明

- 实拍为竖幅构图，裁成 9:16 时保留脸和眼睛居中。
- 白猫实拍的环境是室内家居，暖色偏白平衡。第1集雨夜要更冷，但眼色、粉鼻不要跟着色温改掉。
- 除拼图标明为 AI 生成外，其余为真实拍摄，仅供本项目内部创作使用。
- 参考照片不能代替第1集的瘦弱幼年状态。不要把这些家中实拍直接剪进雨夜成片。
